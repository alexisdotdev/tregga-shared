# Tregga Shared Packages

Paquetes SPM compartidos por las apps del ecosistema Tregga (Delivery, Food, ...).

- **TreggaDesignSystem** — tokens, componentes y patrones de UI (brand Tregga).
- **TreggaCore** — backend compartido: Supabase, Auth, Formatting, Location, Maps, modelos y repos comunes.

Referenciados por ruta local relativa desde cada app (`../tregga-shared/<Paquete>`).
